# pi-agent-view

A supervisor-backed multi-session agent view for [Pi](https://github.com/earendil-works/pi-mono).

This package is currently being specified. Its goal is to let multiple Pi coding sessions continue concurrently across projects while a full-screen thread view provides monitoring, preview, reply, attach, and detach controls.

Regular Pi remains the default; agent mode is explicitly enabled by the user.

## Development

```bash
npm install
npm run check
npm test
```
